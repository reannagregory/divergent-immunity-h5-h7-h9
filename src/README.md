Scripts used to generate figures from the publication "Divergent antibody-mediated population immunity to H5, H7 and H9 subtype potential pandemic influenza viruses".

In particular, the LOWESS curves, correlation matrices, and descriptive serosurvey figures (boxplots, proportion of neutralising samples).

We are not permitted to publish the sample metadata, so source code will not run unless interested parties were to request metadata access from the SNBTS governance board.
